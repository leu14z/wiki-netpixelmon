## 🚀 Como Hospedar no GitHub Pages (Passo a Passo)

O GitHub Pages é uma ferramenta gratuita do GitHub que permite colocar sites estáticos (HTML, CSS, JS) no ar de forma muito simples. Siga os passos abaixo:

### Passo 1: Criar uma conta no GitHub
Se você ainda não tem uma conta, acesse [github.com](https://github.com/) e crie uma.

### Passo 2: Criar um novo Repositório
1. Na sua página inicial do GitHub, clique no botão verde **New** (ou no símbolo **+** no canto superior direito e depois em *New repository*).
2. Dê um nome ao seu repositório (exemplo: `wiki-netpixelmon`).
3. Deixe o repositório marcado como **Public** (Público) — isso é necessário para usar o plano gratuito do GitHub Pages.
4. **Não** marque nenhuma das opções abaixo (*Add a README file*, *.gitignore*, *Choose a license*). Deixe-as desmarcadas.
5. Clique no botão verde **Create repository**.

### Passo 3: Enviar os arquivos pelo navegador (Método Fácil)
Se você não quiser usar comandos do Git no terminal, pode fazer o upload diretamente pelo navegador:
1. Na página do seu repositório criado, você verá a frase *"Get started by creating a new file or uploading an existing file"*. Clique no link **uploading an existing file** (enviar um arquivo existente).
2. Abra a pasta do projeto no seu computador (`C:\Users\bryan\.gemini\antigravity\scratch\netpixelmon-wiki`).
3. Selecione e arraste os seguintes arquivos e pastas para dentro da área de upload do GitHub:
   - `index.html`
   - `style.css`
   - `data.js`
   - `script.js`
   - `assets/` (a pasta inteira contendo o arquivo `logo.png`)
4. Aguarde todos os arquivos carregarem.
5. No campo *Commit changes* na parte inferior, escreva uma mensagem (exemplo: `Primeiro envio da wiki`) e clique no botão verde **Commit changes**.

### Passo 4: Ativar o GitHub Pages
1. No menu superior do seu repositório no GitHub, clique em ⚙️ **Settings** (Configurações).
2. Na barra lateral esquerda, na seção *Code and automation*, clique em **Pages**.
3. Na seção *Build and deployment*, procure por **Branch**.
4. Mude de `None` para `main` (ou `master`, dependendo do nome da sua branch principal).
5. Deixe a pasta marcada como `/ (root)` e clique em **Save** (Salvar).

### Passo 5: Acessar o seu Site!
1. Após clicar em salvar, aguarde de 1 a 2 minutos.
2. Atualize a página do GitHub Pages. No topo, aparecerá uma caixa azul com uma mensagem parecida com: *"Your site is live at..."*.
3. Clique no link gerado (geralmente será `https://seu-usuario.github.io/wiki-netpixelmon/`) para acessar o seu site no ar!
